## 2026-10-13 — P1.2 登录、退出与服务端 Token 失效

- 智能体：Codex

- 需求引用：T-01 P1；FR-01；AC-01

- 实际文件：

  - `apps/api/src/modules/auth/auth.controller.ts`
  - `apps/api/src/modules/auth/auth.guard.ts`
  - `apps/api/src/modules/auth/auth.guard.spec.ts`
  - `apps/api/src/modules/auth/auth.module.ts`
  - `apps/api/src/modules/auth/auth.service.ts`

  - `apps/api/src/modules/auth/dto/login.dto.ts`
  - `apps/api/src/modules/auth/interfaces/authenticated-request.ts`
  - `apps/api/src/modules/auth/interfaces/login-response.ts`
  - `apps/api/src/modules/auth/repositories/auth.repository.ts`
  - `docs/tasks/T-01-backend-core.md`
- 变更摘要：
  - `User` 新增 `tokenVersion`，通过 Migration `20261013142942_p1_auth_session` 应用。
  - `POST /api/v1/auth/login` 校验用户名和密码，拒绝无效凭据与禁用用户，签发包含 `sub`、`username`、`tokenVersion` 的 JWT。
  - 登录响应包含 `accessToken`、`expiresIn`、`tokenType` 和安全用户信息，不返回密码哈希。
  - `POST /api/v1/auth/logout` 在服务端递增 `tokenVersion`，使旧 Token 立即失效。
  - `AuthGuard` 校验 Bearer Token、过期时间、用户状态和 `tokenVersion`，旧 Token、过期 Token 或禁用用户均被拦截。
  - `AuthModule` 集成 `JwtModule`，密钥和过期时间来自环境配置；导出认证 Guard 供后续 P1.3 路由使用。

  - `pnpm dlx pnpm@11.21.0 lint`：通过。
  - `pnpm dlx pnpm@11.21.0 typecheck`：api、desktop、shared 全部通过。
  - `pnpm dlx pnpm@11.21.0 test`：API 8 个测试文件、27 项通过；Shared 6 项通过；Desktop 21 项通过。
  - `pnpm dlx pnpm@11.21.0 build`：api 和 desktop 构建成功。
