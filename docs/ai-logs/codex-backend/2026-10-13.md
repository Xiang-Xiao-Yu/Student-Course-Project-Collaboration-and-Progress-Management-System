- 变更摘要：
  - 启用全局 `ValidationPipe`，未知字段拒绝，DTO 自动转换。
  - `RegisterDto` 校验用户名和昵称长度、密码 8～128 位，并清理首尾空格。
  - `PasswordHasherService` 使用 Node scrypt、16 字节随机盐和 64 字节派生密钥；同时支持安全的 `verify`。
  - `AuthRepository` 负责用户名查询和用户创建；数据库唯一约束竞态映射为 `AUTH_USERNAME_TAKEN`。
  - `AuthService` 先检查用户名，创建前执行密码哈希，响应不包含 `passwordHash`。
  - `AuthController` 提供 `POST /api/v1/auth/register`，成功状态 201。
  - 统一异常过滤器支持受控的大写下划线业务错误码。
  - 共享契约新增认证错误码和用户名、昵称、密码长度规则。
