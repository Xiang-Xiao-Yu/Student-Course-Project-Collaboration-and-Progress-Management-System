### 修复内容

1. 负责人转移并发：
  - 在 Repository 事务内重新读取项目当前负责人、操作者权限和目标成员。
  - 使用 `updateMany` 条件更新 `ownerId`，过期请求返回 `PROJECT_OWNER_TRANSFER_CONFLICT`。
  - 失去 OWNER 权限的旧负责人请求返回 `PROJECT_PERMISSION_DENIED`。
  - 转移时先将其他所有 OWNER 降为 MEMBER，再提升目标成员，保证只有一个 OWNER。
2. 可选字段 null：
  - Create/Update Project DTO 使用 `ValidateIf(value !== undefined)`，null 不再绕过校验。
  - 日期 null、名称 null 和描述 null 均返回 400。
  - 显式空描述更新会真实写入空字符串，审计 afterValue 与数据库一致。
3. 成员头像：
  - ProjectsModule 引入 UsersModule 导出的 AvatarStorageService。
  - 成员列表及邀请/角色更新响应统一把服务器头像引用转换为可显示 data URL；HTTP(S) 头像原样返回，无头像返回 null。
  - 成员接口继续受项目访问控制，项目外用户返回 404。
