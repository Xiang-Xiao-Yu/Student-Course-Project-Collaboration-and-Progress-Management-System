## 评论只读查询

- API：`GET /api/v1/projects/:projectId/comments?targetType=TASK&targetId=:taskId`
- 支持目标：`TASK`、`REQUIREMENT`、`MEETING`。
- 实现：
  - 执行 `PROJECT_VIEW` 权限校验，非项目成员返回不泄露项目存在性的 404。
  - 校验目标对象属于当前项目，目标不存在时返回 `COMMENT_TARGET_NOT_FOUND`。
  - 按创建时间升序返回评论内容、作者和创建/更新时间。
  - 作者上传头像复用 `AvatarStorageService` 转换为 data URL，不返回服务端内部存储引用。

## 操作记录查询

- API：`GET /api/v1/projects/:projectId/activity?targetType=TASK&targetId=:taskId&limit=50`
- 实现：
  - 执行 `PROJECT_VIEW` 权限校验，非项目成员返回 404。
  - 支持按 `targetType`、`targetId` 过滤，`limit` 限制为 1～100，默认 50。
  - 按创建时间倒序返回动作、操作者、目标、时间及 `beforeValue` / `afterValue`。
  - 前后值进行安全 JSON 解析；历史非 JSON 值原样返回，空值返回 `null`。
- 完成时间：继续读取任务详情已有 `completedAt`，不新增冗余接口或字段。
