- 计划验证：客户端选择器正常/取消、持久化和跨会话；接口正常/未认证/大小边界/伪造类型/断网/路径隔离；lint、typecheck、API/桌面测试、构建。
- 风险：multipart 解析器的默认内存限制、魔数检测、路径穿越、文件替换事务和头像 API 的标准 JSON 响应契约；不暴露原始文件路径。
