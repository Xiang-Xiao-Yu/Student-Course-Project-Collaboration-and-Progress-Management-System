# 头像自动上传变更与复测 — 2026-10-21

需求基线 0.1.4；FR-01/AC-11；Issue #26。项目组长要求更换图片后自动上传，移除“上传头像”按钮。

## 最终行为

- 更换图片与相机按钮打开同一文件选择器；通过校验并读取图片后立即上传，无需保存资料。
- 每次有效选择仅上传一次；显示读取/上传中状态，选图及资料保存操作在忙碌期间禁用。
- 上传成功同步头像预览和顶部；取消、非法文件、上传失败均保持旧头像。
- 上传不提交也不丢弃尚未保存的昵称；保存资料只提交昵称，重复保存不上传头像。

## 真实窗口覆盖

1. 只保留文件选择器，URL 编辑和手动上传按钮不存在。
2. 取消选择不产生上传；取消相机选择后保持原头像。
3. 输入未保存昵称后选择有效 PNG，无须其他操作即可自动上传；确认仅一个上传请求、昵称未写入数据库且输入框内容仍保留。
4. 保存昵称、重复保存不产生额外上传；刷新和重新登录后预览、顶部头像和文件标识均正确。
5. 相机鼠标点击与键盘 Enter 打开选择器，选图后自动上传一次并同步顶部。
6. 空文件、不支持格式、超过 10 MiB 被拒绝，不发送上传请求；伪造 PNG 内容由服务端拒绝。
7. 自动上传期间相机、文件输入与保存按钮禁用；网络中断后原文件标识和预览保留，头像操作不发送资料 PATCH。
8. 切换到无头像账号不残留上一账号图片。

其中刷新、顶部、昵称等为运行组内断言。测试使用独立 SQLite、临时 API 端口和随机账号。
