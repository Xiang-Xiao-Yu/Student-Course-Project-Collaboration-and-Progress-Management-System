## 修复

1. 会议创建人使用 `createdById` 在项目成员中回退显示，不再直接读取不存在的 `createdBy`。
2. 验收列表使用摘要 DTO，不读取摘要中的 `participants`。
3. 会议和验收参与人员统一使用返回对象的 `id`，修复编辑请求发送 `[null]`。
4. 行动项转换按 `{ action, task }` 处理，正确显示任务入口。
5. 前端阻止早于项目开始日期的行动项创建和转换；同日期规则仍需后端修正。
