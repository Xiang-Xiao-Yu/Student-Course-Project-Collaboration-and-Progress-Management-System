## 4. 测试等待的正反验证

S12原先只等待旧卡片隐藏；加载态也满足该条件，所以空态尚未生成时就可能断言失败。中间版本仅等待“暂无任务”，仍可能误匹配其他空列已有文字，延迟测试再次暴露这一窗口。最终改为先等待当前筛选汇总明确为0条，再等待空态并断言卡片为0。

- 固定在空结果查询前加入600ms响应延迟，不通过加大超时或任意睡眠代替就绪条件。
- 最终脚本完整运行14/14通过，S12同时保留真实导出失败后按钮可重试的检查。
