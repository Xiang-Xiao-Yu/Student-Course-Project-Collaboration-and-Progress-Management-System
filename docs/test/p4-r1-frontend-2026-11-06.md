## 修复项

1. 逾期标记改为按 `Asia/Shanghai` 日历日比较，截止当天不提前计入逾期。
2. 迭代候选任务显示当前所属迭代；跨迭代加入前要求确认。
3. 迭代编辑内容未保存时，切换迭代需要确认。
4. 保存、状态、加入、移出和关闭的迟到响应不会覆盖当前选中的其他迭代。
5. 统计刷新失败时隐藏旧数字、显示错误并允许重新加载。
