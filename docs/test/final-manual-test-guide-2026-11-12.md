## 1. 启动专用测试环境（开发复现可选）

普通体验优先完整解压最终便携包并双击Start.cmd，无需执行以下开发脚本。下列入口保留给需要复现合成测试场景的开发者。

使用当前已安装并构建的独立源码目录 `C:\Users\Lenovo\.codex\worktrees\p7-full-repro-20261112`。在PowerShell中运行：

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\Lenovo\.codex\worktrees\pr56-regression-fix\Student-Course-Project-Collaboration-and-Progress-Management-System\tests\p7\start-manual-test.ps1"
```

按提示临时设置一个至少8位的测试密码；不需要提供真实账号密码。启动入口只向全新隔离测试库写入合成资料，自动打开桌面客户端。密码不会显示或写入报告、配置和日志，数据库只保存其哈希。

| 账号              | 角色       | 用途                             |
| ----------------- | ---------- | -------------------------------- |
| `manual_admin`    | 平台管理员 | 检查用户管理、禁用和管理员保护   |
| `manual_owner`    | 项目负责人 | 项目、成员、任务审核、验收和导出 |
| `manual_member`   | 项目成员   | 执行任务、评论和会议行动项       |
| `manual_observer` | 观察者     | 核对只读和越权拦截               |
| `manual_other`    | 非成员     | 核对项目隔离                     |

五个账号均使用刚才设置的测试密码。已准备“人工测试普通项目”（初始无任务）和“人工测试万任务项目”（10,000条任务）；负责人、成员、观察者已加入两项目，非成员未加入。注册测试另外新建账号。

保留启动终端。输入 `n` 后回车可打开另一客户端，用不同账号同时测试；输入 `q` 后回车会关闭本次客户端和测试服务。每次重新运行入口都会新建一套测试库，不重置旧库；本次运行中的刷新、关闭再开客户端、退出重登仍使用同一库。若只关闭客户端，在终端输入 `n` 继续本轮。

本次资料路径会显示在终端，保存于当前工作区 `tmp/final-full-2026-11-12/manual-时间戳/`。结束前记下路径及人工结果；现有真实业务数据不参与本次测试。此入口是本机源码测试环境，不是安装包或正式部署。
