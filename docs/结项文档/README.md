# 结项资料总目录

当前 Windows 版本为 0.1.10，需求基线为 0.1.6。请先读[11 月 15 日结项检查](0.1.10-结项检查.md)。下表是 11 月 14 日基线 0.1.4 的历史交付资料；涉及组长移交、Windows 安装及测试结论时以新报告为准。FR-12～FR-15 仍不纳入 MVP。
