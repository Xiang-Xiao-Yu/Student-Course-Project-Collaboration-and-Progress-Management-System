# 系统使用说明书

版本1.0，2026-11-14。面向Windows本机课程团队，覆盖FR-01～FR-11。

## 1. 首次启动

1. 将Windows便携ZIP完整解压到可写目录，保持全部子目录，双击`Start.cmd`。不要仅复制或直接启动`client/SCPC.exe`。
2. 首次启动时为管理员设置8～128位密码，用户名为`admin`。密码以隐藏输入方式读取，交付包没有默认密码。
3. 等待登录窗口出现，使用上述账号登录。后续启动保留原账号和数据，不会重新设置密码。
4. 关闭桌面窗口会停止本次API。数据库、头像及客户端配置位于便携目录`data/`；要搬移时先正常关闭，再移动完整目录。

管理员管理账号；项目负责人负责自己项目的成员、计划、审核、验收和导出；成员执行任务、评论和会议行动项；观察者只读。项目角色与平台管理员标记分开，由后端判断权限。

## 2. 账号和个人资料

普通成员可从注册入口创建账号。登录后在个人资料修改昵称、选择头像或修改密码。选择有效JPEG、PNG、WebP图片后自动上传，单个文件不超过10MiB；取消或失败保留原头像。昵称单独保存，不随头像自动上传提交。退出或改密会使旧会话失效。

平台管理员进入“用户管理”，选中普通用户，输入其用户名二次确认后禁用。管理员账号受保护，不能禁用；取消不改变数据。禁用立即使目标旧会话失效，历史任务、成员关系和操作记录保留。

## 3. 创建项目和邀请成员

从项目中心创建项目，填写名称及需要的说明、起止日期。进入成员管理，选择已注册用户并设置角色。结束日期不得早于开始日期。移除成员不删除历史；负责人移交后才能退出负责人职责。

项目暂停后不能新增业务数据，恢复后继续；归档项目只读。删除项目需要二次确认，按实际需求操作。日常测试建议新建独立项目。

## 4. 需求与任务看板

1. 在需求管理填写标题、说明、优先级和验收标准。
2. 在任务看板创建任务，选择当前项目成员作为负责人，关联需求并设置优先级、截止日期、标签及预估工时。
3. 看板按状态显示。每列最多显示50条，表头是该列完整数量；通过上一页、下一页或页码选择访问其他任务。跨列拖拽仍按任务状态规则执行。
4. 输入标题或组合负责人、状态、优先级、标签、迭代和截止日期筛选，点击应用筛选；清空筛选恢复完整结果并回到首屏。
5. 成员开始任务、填写完成说明并提交审核；负责人审核后进入已完成。审核驳回会显示原因，修正后可再次提交。重开已完成任务必须说明原因。

分页只控制卡片显示，统计总数和导出均使用完整匹配数据。不要用当前屏幕卡片数代替项目总数。

## 5. 迭代、评论和会议

负责人创建迭代，安排目标和日期，将任务加入迭代，查看总数、完成、阻塞和逾期统计。关闭时按界面处理未完成任务。评论可发布在需求、任务和会议；只修改或删除自己有权限处理的评论。

创建会议并填写时间、议程和参与人，记录纪要和决定，再为行动项设置负责人、截止日期和状态。行动项可转为普通任务，转成后可跳转查看；重复操作不会创建重复关联任务。

## 6. 阶段验收和整改

负责人创建阶段、目标、标准、参与人及可选验收日期。选择未通过时填写原因并生成整改任务；整改按任务流程执行、提交审核后，再记录验收结果。整改处理或恢复期间，界面会限制相互冲突的创建和切换操作。

已有验收日期可以编辑或清空后保存；刷新后仍保留清空结果。遇到网络失败时先查看提示，使用重试恢复，不要把按钮暂时忙碌视为保存成功。

## 7. 统计与文件导出

概览展示任务状态、成员分布、迭代完成率、需求完成率、完成趋势、燃尽图、最近操作和即将到期任务。历史完成事件与当前已完成任务数口径不同，重开或删除任务后两者不必相等。

项目负责人或管理员可导出任务CSV及基础进度报告。按实际下载提示保存文件，文件含UTF-8 BOM便于表格软件识别中文。筛选100条时，即使当前页仅显示50张卡片，CSV仍有全部100条。

## 8. 常见问题

| 现象                         | 处理                                               |
| ---------------------------- | -------------------------------------------------- |
| 会话过期、退出后旧窗口被拦截 | 重新登录；重启便携服务会更新会话密钥               |
| 用户被禁用                   | 由平台管理员核对；本版不提供启用或删除账号扩展     |
| 空项目或没有匹配任务         | 查看空态提示或清空筛选，不代表数据丢失             |
| 启动失败                     | 先确认完整解压、目录可写，再查看部署说明；保留data |
| 下载失败                     | 检查目录和网络提示，重试；失败不会记作已导出成功   |

不包含通用附件管理、GitHub双向同步、复杂通知、甘特图、系统内备份恢复或多组织功能。组长可补充体验，不需要先改动源码、配置或既有数据。
