# 最终交付清单

交付标识：`SCPC-0.1.0-closeout-20261114`。需求0.1.4，MVP范围FR-01～FR-11、AC-01～AC-11。

## 1. 产物

原项目可直接访问的交付目录为`deliverables/final-20261114/`，另在本轮独立工作区保留`release/closeout-20261114/交付/`，两处ZIP逐字节一致，不覆盖原有阶段包。

| 文件                        | 用途                                                           |
| --------------------------- | -------------------------------------------------------------- |
| `SCPC-Windows-Portable.zip` | Windows完整便携运行包；解压后双击Start.cmd                     |
| `SCPC-Source.zip`           | 最终候选源码、锁文件、迁移、脚本及文档，不含运行数据或依赖目录 |
| `SCPC-Documents.zip`        | 结项正文、正式基线及精简技术证据                               |
| `SHA256SUMS.txt`            | 上述ZIP的SHA-256                                               |
| `delivery-manifest.json`    | 文件大小、散列、产品文件清单及技术验证索引                     |

最终文件位于项目本轮`release/closeout-20261114/交付/`。运行包不需要用户修改项目、安装数据库或配置开发环境；首次按启动器提示设置管理员密码即可。

## 2. 版本和内容

源码基于main合并版本`0932ae204533ec50ec0237b81a2343e39e15dd43`，包含2026-11-14的万任务分页、等待、动作中文和日期清空修复。精确内容以随包manifest的逐文件SHA-256为准；未把Git产品树散列冒充提交号。

源码包排除`.git`、node_modules、构建缓存、真实.env、SQLite、头像、浏览器profile、临时账号及完整运行日志。便携包只放运行时、构建产物、生产依赖和迁移；新包没有data目录。迁移及初始化发生在用户解压目录，既有仓库数据不受影响。

## 3. 完整性与复现

精简技术结果和源码复现索引见[evidence/technical-summary.json](evidence/technical-summary.json)。源码候选包已独立解压、冻结锁文件离线安装、Prisma生成及两端构建通过；最终归档再次核对同一产品与契约文件。

在交付目录可使用PowerShell检查单个文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\SCPC-Windows-Portable.zip
```

将输出与SHA256SUMS.txt或delivery-manifest.json核对。验证已包括独立ZIP解包、完整性、首次初始化、真实桌面登录、日期清空、头像目录、退出重启、设备缩放与本机网卡访问。原始测试证据保留在本机工作区，不把它们当成用户运行所需文件。

用户补充体验是可选复核。技术验收结论见[项目验收报告](项目验收报告.md)，环境边界见[最终测试报告](最终测试报告.md)，实际使用见[系统使用说明书](系统使用说明书.md)。
