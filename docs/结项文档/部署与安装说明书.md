# 部署与安装说明书

版本1.0，2026-11-14。本次正式运行形态为Windows本机便携版，同时提供源码。便携ZIP通过独立解包验证，内含Node24.18.0、Electron44.4.3、API生产依赖及Prisma迁移，不需要另装Node、数据库或开发工具。

## 1. 便携运行

中文和空格目录下的初始化、桌面登录、头像、重启及正式启动入口退出已另行验证，无需为运行改为英文目录。

完整解压到当前用户可写目录，双击`Start.cmd`。入口只为本次启动调用PowerShell，不修改系统执行策略、PATH、防火墙或系统服务。首次交互设置管理员密码，用户名`admin`；没有固定默认密码，密码不写入交付包或日志。

API默认仅绑定127.0.0.1并选择空闲端口，桌面自动使用同一地址。JWT密钥每次启动在进程内生成，因此重启后需要重新登录。关闭桌面窗口会停止配套API；数据保持。

| 位置                                             | 内容                                       |
| ------------------------------------------------ | ------------------------------------------ |
| `Start.cmd`、`Start-System.ps1`、`bootstrap.mjs` | 启动和退出管理                             |
| `runtime/`                                       | Node执行程序及许可                         |
| `client/`                                        | Electron执行程序、资源及桌面构建产物       |
| `apps/api/`                                      | API构建产物、完整生产依赖、Schema与5条迁移 |
| `data/app.sqlite`                                | 首次运行建立的独立数据库                   |
| `data/avatars/`                                  | 实际上传的头像                             |
| `data/client-profile/`                           | 便携桌面配置与会话                         |
| `data/last-session.json`                         | 非凭据运行状态，含临时端口和进程标识       |

保持上述目录层级，尤其不要移动apps/api的内部文件。迁移通过Prisma部署，不手工改数据库结构；新包不包含账号、SQLite、头像或客户端会话。替换版本前正常关闭，按实际运维要求保全原数据，不执行自动覆盖或删除。

## 2. 源码构建

需要Node至少24.18.0、pnpm11.21.0；实际锁定依赖以pnpm-lock.yaml为准。在独立解压目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm db:generate
```

将`.env.example`复制为本地`.env`，把JWT_SECRET设置为仅本机持有的足够长随机值，确认DATABASE_URL指向独立数据目录，再执行：

```powershell
pnpm db:migrate
pnpm build
pnpm dev
```

正常使用优先选择已经验证的便携版。源码运行注册自己的普通账号即可创建项目并成为项目负责人；开发种子仅适合独立演示库，不用于覆盖真实库。管理员入口的完整初始化由便携启动器负责。

## 3. 重建便携包

完成依赖安装、Prisma生成和两端构建后，传入一个尚不存在的输出目录及锁定Electron的dist目录：

```powershell
node scripts/package-portable.mjs <新的输出目录> <Electron的dist目录>
```

脚本仅复制本机已安装的生产依赖及执行程序，不下载或升级软件；保留包内许可和Node对应版本许可。遇到既有输出目录会拒绝覆盖。ZIP由Windows压缩库生成，交付清单提供SHA-256。

## 4. 网络与环境边界

本机便携运行是本次验收环境。API还实测了通过本机非回环网卡地址登录和读取项目，但这不是第二台实体设备验证，也没有自动开放防火墙。若以后选择局域网部署，应独立配置API监听、CORS和客户端地址，并按实际网络验收；不影响本机交付可用。

100%、125%、150%、200%的Electron设备缩放和960×640最小窗口已测试。不同物理显示器、跨屏混合DPI及长期连续负载不从这些结果外推。当前包为便携应用，没有制作MSI/NSIS系统安装、卸载或自动更新流程。

## 5. 排错与数据保留

启动失败时确认目录可写、文件完整、磁盘空间足够，并保留data文件夹。首次密码不足8位会拒绝初始化；重新启动输入有效密码即可，不需要清空文件。账号存在后启动不会重置密码。程序异常退出时先确认旧进程已关闭，再重新启动，不手工运行多个同目录实例。

移除应用时先正常关闭，再按需要将完整目录移至回收站。系统不自动删除数据，也不自动备份用户文件。交付包校验不一致时重新从原交付位置取得文件，保留现有运行目录。
