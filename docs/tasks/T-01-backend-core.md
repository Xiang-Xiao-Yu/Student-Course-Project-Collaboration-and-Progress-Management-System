## 任务边界

本任务负责 NestJS、Prisma、SQLite、身份认证、服务端权限、核心业务 Service/Controller、统一错误处理和供前端使用的 API 契约。任务负责人按 `root` 批准的范围实施；公共类型、数据库结构、依赖和安全配置必须遵循 `root` 的统一约定。

任务未认领前，所有其他智能体只能阅读本文件。认领并经 `root` 确认后，负责人才能修改本任务允许的代码、Schema、Migration、配置和测试；其他智能体不得介入。

## 认领规则

其他智能体认领时必须使用自己的名称化标签，例如 `DeepSeek@backend`，向 `root` 报告并等待确认。确认后，标签、分支、日志和 PR 必须保持一致；负责人只能修改本任务的进度、验证和交接区域，以及 `root` 明确批准的实现文件。

## 阶段与小功能

所有阶段必须按顺序推进。当前阶段由三人分别完成自己的任务；`T-01` 和 `T-02` 都标记 `待测试` 后，全员立即冻结，停止当前阶段以外的开发。由 `T-03` 统一检查，只有测试通过并由 `root` 明确解锁后，才能进入下一阶段。测试失败时只能修复当前阶段，修复后再次冻结并交由 `T-03` 复测。

阶段门禁状态：`开发中 → 全员待测试 → 全员冻结 → T-03 检查中 → 检查失败/当前阶段修复 → T-03 复测 → root 解锁下一阶段`。

### P0 基础工程与契约

- P0 的运行时、目录边界、启动命令、环境变量、服务地址、API 响应和数据库约定以 [P0 工程与契约约定](../P0-工程与契约约定.md) 为准；冲突必须先提交 GitHub Issue 给 `root`。
- P0.1 锁定项目目录、启动命令、环境变量模板和统一响应/错误格式。
- P0.2 建立 Prisma Schema、SQLite 连接、Migration 和最小种子数据。
- P0.3 建立模块边界：Auth、Users、Projects、Requirements、Tasks、Iterations、Comments、Meetings、Acceptances、Dashboard。
- P0.4 输出 API 路径、请求校验、权限前置条件和状态枚举，供前端和测试使用。
- 门禁：服务能启动；Migration 可执行；未配置密钥时不泄露敏感信息；P0 测试通过。

### P1 用户认证

- P1.1 注册、用户名唯一校验和密码安全哈希。
- P1.2 登录、退出、会话过期、禁用用户拦截和服务端 token 失效。
- P1.3 当前用户资料和个人任务查询。
- 门禁：对应 AC-01 的正常、重复用户名、无效凭据、禁用用户和旧 token 失败场景通过。

### P2 项目、成员与权限

- P2.1 项目创建、编辑、状态流转、归档和删除二次确认所需 API。
- P2.2 成员邀请、角色设置、移除成员和历史记录保留。
- P2.3 项目级数据隔离、观察者只读、负责人和管理员权限校验。
- 门禁：对应 AC-02、AC-08；覆盖跨项目访问、越权写入、负责人自移除和无效日期失败场景。

### P3 需求、任务与状态记录

- P3.1 需求 CRUD、验收标准、状态和任务关联。
- P3.2 任务 CRUD、负责人、优先级、截止日期、标签、完成说明和关联需求。
- P3.3 看板状态流转：待规划、待开始、进行中、待审核、已完成、已阻塞；完成前置条件和重新打开原因。
- P3.4 所有状态变更写入 ActivityLog，并保存完成时间。
- 门禁：对应 AC-03、AC-04；覆盖正常流转、无负责人、无效日期、越权修改和无完成说明失败场景。

### P4 迭代、评论与操作记录

- P4.1 迭代 CRUD、日期校验、任务加入/移出和状态流转。
- P4.2 迭代统计：总数、已完成、进行中、阻塞、逾期和完成率。
- P4.3 任务、需求、会议评论的创建、修改本人评论和删除本人评论。
- P4.4 操作记录查询和脱敏输出。
- 门禁：对应 AC-05；覆盖组合统计、空迭代、评论越权和活动记录完整性。

### P5 会议与阶段验收

- P5.1 会议、参会人员、议程、纪要和决定。
- P5.2 行动项及状态：待处理、进行中、已完成、已取消。
- P5.3 行动项负责人/截止日期校验和转换为普通任务。
- P5.4 阶段验收、未通过原因、整改任务和再次验收。
- 门禁：对应 AC-06、AC-07；覆盖正常创建、空标题、无权限验收、未通过原因缺失和转换失败场景。

### P6 仪表盘、筛选与导出

- P6.1 项目概览、任务状态、成员任务、迭代完成率、需求完成率和近期活动统计。
- P6.2 完成趋势和简单燃尽图所需查询数据。
- P6.3 负责人、状态、优先级、标签、迭代和截止日期组合筛选。
- P6.4 CSV 任务列表和基础进度报告导出。
- 门禁：对应 AC-09、AC-10；覆盖空项目、组合条件、无结果、非法参数和导出失败场景。
