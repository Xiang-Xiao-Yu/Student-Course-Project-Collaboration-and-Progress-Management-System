# 跨模块测试

本目录由 T-03 负责，用于保存跨模块测试、阶段门禁检查和可复核证据。T-01、T-02 的实现测试继续位于各自工作区中。

## 目录约定

- `tests/p0/`：P0 工程与契约检查。
- 每个阶段使用独立子目录，例如 `tests/p1/`、`tests/p2/`。
- 文件名使用 `check-<场景>.mjs` 或 `<范围>.test.ts`，测试编号使用 `P0-<区域>-<序号>`。
- 自动化检查不得修改业务实现来制造通过结果。
- 测试数据和运行产物不得提交；本地数据库、日志和临时截图保留在忽略目录中。

## P0 命令

```powershell
pnpm test:p0-env
pnpm test:p0-smoke
```

- `test:p0-env` 输出 Node、pnpm、Git 提交和必要环境变量是否存在，不输出密钥值。
- `test:p0-smoke` 检查正在运行的 API 是否满足 P0 健康检查和统一错误响应契约。
- 冒烟检查默认访问 `http://127.0.0.1:3000/api/v1`，可通过 `P0_API_BASE_URL` 覆盖。
- API 尚未实现时，`test:p0-smoke` 会失败并返回非零退出码，这是阶段门禁的正确结果。

## 证据要求

每轮检查必须在 `docs/test/p0-evidence-template.md` 中记录冻结提交、环境、完整命令、原始结果、失败原因、风险和结论。不得只记录“通过”或“失败”。
